Dice Pools & Tests

In Shadowrun 5th Edition, all actions are resolved using six-sided dice (d6). The basic mechanic involves building a dice pool based on your attributes and skills, rolling the dice, and counting successes.

Basic Formula

Dice Pool = Attribute + Skill + Modifiers

Attribute + Skill Combination

Most tests combine one attribute with one skill. For example:

Test Type Formula Example
Physical Test Strength + Athletics Climbing a wall
Social Test Charisma + Persuasion Negotiating a deal
Technical Test Logic + Computers Hacking a system
Combat Test Agility + Firearms Shooting at a target

For more information on attributes, see Attributes page.

Counting Successes

After rolling your dice pool, count the number of dice that show a 5 or 6. Each 5 or 6 counts as one success (also called a "hit").

Exploding Sixes (Optional Rule)

Some groups use the "exploding sixes" rule: when you roll a 6, you may reroll that die and add additional successes. Check with your gamemaster.

Example Roll

Situation: A runner attempts to pick a lock.

  • Attribute: Agility 4
  • Skill: Locksmith 3
  • Modifiers: None
  • Dice Pool: 4 + 3 = 7 dice
Roll: [2] [3] [5] [5] [6] [1] [4]
Successes: 5, 5, 6 = 3 hits

This action succeeds with 3 hits.

Thresholds & Limits

Threshold

The threshold is the minimum number of hits required for a test to succeed. Thresholds are set by the gamemaster based on task difficulty:

Difficulty Threshold Description
Simple 1 Routine task, minimal challenge
Standard 2-3 Moderate difficulty
Hard 4-5 Challenging task
Very Hard 6+ Extremely difficult, nearly impossible

Limits

Limits represent the maximum number of hits you can achieve on a test, regardless of how many dice you roll. There are three types of limits:

Limit Type Applies To
Physical Limit Physical actions (running, jumping, melee combat)
Mental Limit Mental actions (hacking, research, perception)
Social Limit Social interactions (negotiation, intimidation, etiquette)

Note: In SR5, limits are typically calculated as half of the relevant attribute (rounded up) plus any modifiers.

Opposed Tests

When two characters oppose each other directly, both parties roll their dice pools. The character with more hits wins. The margin of success is the difference between the winner's hits and the loser's hits.

Opposed Test Resolution

Net Hits = Winner's Hits - Loser's Hits

Example

Situation: A stealthy runner tries to sneak past a guard.

  • Runner: Agility + Stealth = 6 dice → rolls 4 hits
  • Guard: Logic + Perception = 5 dice → rolls 2 hits
  • Result: Runner wins with 2 net hits (4 - 2 = 2)

If both parties roll the same number of hits, the test is a tie and must be rerolled, or the status quo remains (typically favoring the defender).

Extended Tests

Extended tests are used for complex tasks that require multiple rolls over time. Each roll represents a time interval (minutes, hours, days, etc.).

Rules

  1. Set a cumulative threshold (usually much higher than a simple test)
  2. Roll your dice pool once per time interval
  3. Add hits from each roll to a running total
  4. Continue until you meet/exceed the threshold or run out of time
Glitches & Critical Glitches

If more than half of your dice show 1s, you glitch. On a critical glitch (all 1s with no hits), something goes catastrophically wrong and the test automatically fails.

Example

Situation: A decker is trying to crack a secure system (Threshold: 12 hits, Interval: 1 minute)

  • Roll 1: 3 hits (Total: 3)
  • Roll 2: 4 hits (Total: 7)
  • Roll 3: 2 hits (Total: 9)
  • Roll 4: 5 hits (Total: 14) → SUCCESS!

Total time elapsed: 4 minutes

Teamwork Tests

When multiple characters work together on a task, one character is designated as the primary actor, and others provide assistance.

Mechanics

  1. Each assistant makes a relevant skill test (Threshold: 1)
  2. For each hit the assistants achieve, the primary actor gains +1 die to their pool
  3. The primary actor then makes their test with the augmented dice pool
Teamwork Example

Three runners help their hacker breach a system. Each makes an Intelligence + Computers test (Threshold 1). They score 2, 1, and 3 hits respectively. The primary hacker gains +6 dice to their hacking pool.
