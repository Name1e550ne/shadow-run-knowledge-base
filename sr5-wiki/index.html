Cross-Reference System

This wiki uses a strict ID-based cross-referencing system for easy navigation:

Content Type ID Format Example Link
Attributes attributes.html#{name} attributes.html#agility
Skills skills.html#{name} skills.html#stealth
Spells magic.html#{spell-name} magic.html#mana-bolt
Combat Rules combat.html#{topic} combat.html#initiative
Gear Items gear.html#{item-name} gear.html#ares-predator
Pro Tip

All IDs use lowercase with hyphens for multi-word terms. For example: "Mana Bolt" becomes #mana-bolt, "Full Auto" becomes #full-auto.

Getting Started

To use this wiki:

  1. Open index.html in any modern web browser
  2. Use the navigation menu or search box to find information
  3. Click on cross-referenced links (styled in cyan) to jump to related topics
  4. Bookmark specific sections using the URL anchors (e.g., attributes.html#agility)
